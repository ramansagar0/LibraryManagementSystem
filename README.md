# Library Management System

## Project Overview

A digital Library Management System developed using Java, Java Swing, MySQL, JDBC, and Maven.

The system helps manage books, members, book issue/return records, and library operations through a simple desktop interface.

## Features

- User Login
- Dashboard
- Book Management
- Add, View, Search, Update and Delete Books
- Member Management
- Add, View, Search, Update and Delete Members
- Issue Books
- Return Books
- Automatic Book Availability Tracking
- MySQL Database Integration

## Technologies Used

- Java 17
- Java Swing
- MySQL
- JDBC
- Maven
- Git
- GitHub
